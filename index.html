🍈 ARSLAN LISTAS PRO v4.0

Pedidos + Catálogo + Proveedores + Reparto
Flujo recomendado: Catálogo → Pedidos (destinos) → Global (asignar proveedor) → Proveedores (TXT/WhatsApp) → Reparto
🏷️ Catálogo de productos (precios + historial + unidades)
Consejo: el catálogo alimenta autocompletado, duplicados y precios.
Cada producto puede tener precio distinto por proveedor + historial.
📚 Vocabulario (estandarización)
Un producto por línea. Se normaliza a MAYÚSCULAS sin tildes. Evita duplicados.
🧾 Pedidos por destino (tiendas + hoteles/restaurantes)
Si un destino no tiene pedido, no aparecerá en Reparto.
Cantidades inteligentes: “2 cajas”, “22 kg”, “3x2”, “1/2”, “x4”. Unidades: kg/caja/ud/manojo/saco.
Edita en la tabla: OK = verde, Revisar/duplicado = rojo. Autocompletado activo.
🧮 Global (compra total) + Asignación a proveedores
Puedes incluir solo hoteles o solo tiendas, o todo.
Menos toques: Swipe → asignar / Swipe ← deshacer. Teclado: Enter asigna, Ctrl+Z undo.
—
📦 Pedidos por proveedor (salida TXT/WhatsApp)
Aquí ves lo asignado a cada proveedor desde Global. Puedes editar cantidades y nombres.
🚚 Reparto por destino (lo que se entrega a cada uno)
Solo aparecen destinos con pedido.
Puedes seleccionar líneas para preparar entrega. Incluye precio si lo activas.

Atajos
Global: Enter asigna | Ctrl+Z deshacer | Ctrl+Y rehacer | 1-9 cambia proveedor | / enfoca búsqueda
